# Linux Reference Guides

A collection of practical, no-fluff Linux administration guides covering the topics you actually need day to day — from managing files and permissions to networking, processes, packages, services, and users.

Each guide is a standalone Markdown file you can read straight from GitHub or clone locally for quick reference.

## 📚 Contents

| Guide | Description |
|---|---|
| [Linux File Management](./linux-file-management.md) | Core commands for navigating, creating, copying, moving, and deleting files and directories |
| [File Permissions & Ownership](./linux-file-permissions-and-ownership.md) | Understanding `chmod`, `chown`, `chgrp`, and the Linux permission model |
| [Linux Networking](./linux-networking.md) | Networking basics — interfaces, IP configuration, DNS, and common troubleshooting commands |
| [Process Management](./linux-process-management.md) | Monitoring and controlling processes with `ps`, `top`, `kill`, `nice`, and job control |
| [Package Management](./package-management.md) | Installing, updating, and removing software on Ubuntu/Debian-based systems |
| [Service Management](./service-management.md) | Managing services with `systemd` — starting, stopping, enabling, and checking status |
| [Users & Groups](./users-and-groups-guide.md) | Creating and managing users, groups, and privilege escalation with `sudo` |

## 🎯 Purpose

This repo started as a personal reference while learning Linux system administration, and is meant to serve as:

- A quick lookup for commonly used commands and flags
- A study resource for anyone learning Linux fundamentals
- A living document that grows as new topics are covered

## 🛠 How to Use

Browse the guides directly on GitHub, or clone the repo for offline access:

```bash
git clone https://github.com/YounusPeerzada/learning-linux.git
cd learning-linux
```

Each file is self-contained, so you can jump straight to the topic you need.
